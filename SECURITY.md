# Security policy

## Reporting a vulnerability

Please report security issues privately to [support@fincopy.io](mailto:support@fincopy.io). Include the affected package
and version, a description of the issue, and steps to reproduce it. Do not disclose vulnerabilities in a public issue
before FinCopy has had a reasonable opportunity to investigate and prepare a fix.

Never include an API key, access token, webhook secret, or account credential in a report.
